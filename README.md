# 同封するお手入れカード

100日100プロダクトチャレンジ Day092（2026-11-07）

作品の素材を選んで質問に答えると、使い方とお手入れを書いた同封カードができるWebページです。

- 素材は8つ（木／陶器・磁器／布／革／金属のアクセサリー／ガラス／キャンドル／ドライフラワー・押し花）
- カードに書くのは、作り手が答えたことだけです。答えていない質問はカードに出ません
- A4に4枚並べて印刷できます（1枚 99×138mm）。同じ文をコピーして、商品ページにも貼れます
- 食品・化粧品・石けん・アロマは扱いません（表示する内容が法律で決まっているため）

## 使い方

`index.html` をブラウザで開きます。「見本を入れる（木の器）」「見本を入れる（真鍮のピアス）」で架空の例を入れられます。

## 扱うデータ

- 入力はこの端末のブラウザの中だけで扱い、当サイトには送信しません
- 入力は、この端末のブラウザ（localStorage）に下書きとして残ります
- カードの内容は作り手の答えをそのまま並べたもので、内容が作品に合っているかは確かめていません
- アクセス解析（Cloudflare Web Analytics）でページの閲覧状況を計測しています
